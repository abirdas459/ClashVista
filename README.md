## 🚀 Installation

1. Download **`ClashVista_v1.0.0.msi`** from the [Releases](Autodesk App Store).
2. Double-click the `.msi` file to launch the setup wizard.
3. Follow the on-screen instructions to complete the 1-click installation.
4. Launch Autodesk Revit (2021 – 2026). The **ClashVista** ribbon tab will appear automatically.

## 🗑️ Uninstallation

To remove ClashVista from your system:
1. Open Windows **Settings** > **Apps** > **Installed Apps** (or **Control Panel** > **Programs and Features**).
2. Search for **ClashVista**.
3. Click **Uninstall**.
